# VTA Panel

Hosted release binaries for [VTA Panel](https://vtapanel.com).

## Install

```bash
curl -fsSL https://vtapanel.com/latest/install | sudo bash
```

That script downloads `vtapanel-linux-amd64` / `vtapanel-linux-arm64` from [Releases](https://github.com/sanyogs/VTA.Panel/releases/latest).

Source and docs live in the product monorepo; this repository is for GitHub Releases distribution.
